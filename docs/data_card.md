
# Data Card: Kakul Garlaniyan In-Situ Geochemical Dataset

## 1. Dataset Identification

**Dataset:** In-situ geochemical measurements from the Early Cambrian Kakul Garlaniyan phosphorites, northeastern Pakistan.

**Source:** Supplementary Table S2 of Ali et al. (2026).

**Original workbook:** Supplementray_files.xlsx

**Worksheet:** Supplementary file 2

**Research application:** Grain-type variation and prediction of total rare earth element and yttrium (REY) concentrations.

## 2. Data Source and Provenance

The dataset originates from published research on the Kakul Garlaniyan phosphorites of the Hazara Basin, northeastern Pakistan.

The original study investigated phosphogenesis using petrographic and geochemical observations.

This Data Science project reuses the published in-situ measurements for exploratory statistical comparisons and predictive modelling.

The original measurements were not generated by this Data Science project.

## 3. Dataset Size and Structure

The dataset contains 103 analytical measurements from three phosphorite layers:

- Lower phosphorite layer (LPL)
- Middle phosphorite layer (MPL)
- Upper phosphorite layer (UPL)

The analytical measurements are distributed among four phosphatic-component categories:

| Component | Measurements |
|---|---:|
| Oolite core | 35 |
| Oolite rim | 27 |
| Pellet core | 20 |
| Pellet rim | 21 |
| **Total** | **103** |

The observation unit is an individual analytical spot, not necessarily an independent rock sample.

## 4. Variables Used in the Project

### Prediction target

Total REY concentration, expressed in parts per million (ppm).

The dataset contains total REY concentrations ranging from 222.77 to 922.74 ppm, with a mean of 587.87 ppm.

### Predictive variables

The model comparison uses:

- Petrographic grain type: oolite or pellet
- F
- Na2O
- MgO
- FeO
- P2O5
- CaO
- MnO
- Al2O3
- SiO2

Major-element concentrations are treated as numerical predictors.

Grain type is treated as a categorical predictor.

Individual REY concentrations and REY-derived indices are excluded from predictors of total REY to avoid target leakage.

### Stratigraphic and grouping variables

Stratigraphic-layer labels and analytical-point identifiers are used to construct provisional parent-rock groups.

These identifiers are used for grouping and evaluation, not as model predictors.

## 5. Data Preparation and Quality Considerations

The published spreadsheet contains merged cells for some descriptive labels.

The Python import procedure forward-fills the layer and mineral-phase labels to recover the analytical categories.

Records without analytical-point identifiers are excluded from the imported analysis table.

The initial audit recovered 103 analytical measurements.

Numerical predictor preprocessing in the regression pipeline uses training-set median imputation and standardization.

A complete missing-value inventory and verification against the original analytical records remain to be documented.

No missing values or unusual measurements should be silently replaced in the source workbook.

## 6. Sampling Structure and Dependence

The dataset contains multiple analytical spots that may originate from the same parent rock.

Using stratigraphic labels and analytical-point prefixes, the project identifies 26 provisional parent-rock groups.

Thirteen inferred groups contain both oolite and pellet measurements.

These group assignments have not yet been independently verified against the original sample records.

Consequently, the number of confirmed independent geological samples remains unresolved.

The project uses group-aware validation to reduce the risk of assigning measurements from the same inferred group to both training and testing sets.

## 7. Intended Uses

The dataset is used to:

1. Describe the distribution of total REY concentrations among phosphorite layers and grain types.
2. Examine differences between oolites and pellets within inferred parent-rock groups.
3. Compare simple regression models for predicting total REY concentrations.
4. Evaluate preliminary model sensitivity to training-set size.

The dataset is intended for exploratory analysis and reproducible methodological evaluation.

## 8. Limitations and Inappropriate Interpretations

The dataset represents one geological locality and a limited number of inferred parent rocks.

Individual analytical measurements must not automatically be treated as independent geological samples.

The grain-type labels are derived from existing petrographic descriptions. They are not predictions obtained from automated image analysis.

The dataset cannot independently establish the geological processes responsible for REY enrichment.

Cross-validation results do not demonstrate model transferability to other phosphorite deposits.

Statistical associations should not be interpreted as evidence of geological causation.

## 9. Data Rights, Ethics, and Access

The dataset originates from a published scientific study.

Publication of the article and supplementary material does not automatically establish unrestricted permission for redistribution or machine-learning use.

Applicable publisher conditions, author permissions, and research-data reuse rights must be checked before distributing the original workbook.

The original workbook is retained locally at:

`data/raw/Supplementray_files.xlsx`

The public repository should not include the original workbook unless permission has been confirmed.

The dataset concerns geological measurements and does not contain human-subject records.

## 10. Reproducibility

The original workbook is required to reproduce the calculations.

The source data are read by Python scripts located in the `scripts/` directory.

Generated analytical results are stored under `results/`.

The software dependencies are documented in:

- `requirements.txt`
- `requirements-lock.txt`

Instructions for executing the analysis are provided in `README.md`.
